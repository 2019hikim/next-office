# 다음오피스 한글

교사가 한 쪽짜리 수업 안내문을 써서, 학생이 한컴 한글에서 열 수 있는 **HWPX** 파일로 전달하는 문서 편집기입니다.
설계안: [docs/한글문서_에디터_초기설계_v1.md](docs/한글문서_에디터_초기설계_v1.md) · 완료 기준: [SPEC.md](SPEC.md)

외부 라이브러리 없이 순수 HTML · CSS · 자바스크립트로 만들었고, 설치나 빌드 없이 브라우저로 바로 엽니다.

## 실행

`index.html`을 **Chrome 또는 Edge**로 엽니다.

- 파일 고르기 창(열기·저장)과 압축된 HWPX 풀기는 Chrome·Edge 기준입니다.
- 그 밖의 브라우저에서는 저장이 "내려받기"로 바뀝니다.

## 기능

| 구분 | 기능 | 단축키 |
|---|---|---|
| 파일 | 새 문서, 열기(.hwpx · .txt, 끌어다 놓기도 됨), 저장, 다른 이름으로 저장 | Alt+N, Ctrl+O, Ctrl+S, Ctrl+Shift+S |
| 파일 | 저장하지 않은 문서를 바꾸거나 닫을 때 확인 (저장 / 저장 안 함 / 취소) | |
| 파일 | 임시 저장: 저장하지 않은 글을 이 브라우저에 1초마다 남기고, 다시 열 때 복구를 묻습니다 | |
| 편집 | 한글 입력, Enter(새 문단), Shift+Enter(문단 안 줄바꿈), Tab, 붙여넣기(글자만), 실행 취소·다시 실행 | Ctrl+Z, Ctrl+Y |
| 글자 | 글꼴, 크기(pt), 굵게, 기울임, 밑줄, 취소선, 글자 색 | Ctrl+B, Ctrl+I, Ctrl+U |
| 문단 | 정렬(왼쪽·가운데·오른쪽·양쪽), 줄 간격(%) | |
| 쪽 | A4 용지, 한컴 기본 여백, 편집 화면의 쪽 경계 점선, 쪽 수·글자 수 표시, 확대 50~200% | |
| 미리보기·인쇄 | A4 쪽 나누기와 쪽 번호를 미리 보고, 같은 모양으로 인쇄합니다 (긴 문단도 줄 사이에서 나눕니다) | Ctrl+P, Esc(미리보기 닫기) |

HWPX에는 글자 모양(글꼴·크기·굵게·기울임·밑줄·취소선·색)과 문단 모양(정렬·줄 간격)을 담아 저장하고, 다시 열면 그대로 돌아옵니다.

## 아직 안 되는 것

- HWP(옛 형식) 열기·저장, 표, 그림, 머리말·꼬리말, 쪽 나누기 넣기, 여러 구역
- 한컴 한글이 만든 HWPX는 본문 글자와 위 모양만 읽습니다. 표 안의 글자 등은 건너뜁니다.
- Windows 전용 앱(Electron) 포장은 다음 단계입니다 (설계안 R1).

## 테스트

```bash
node tests/run-tests.js
```

- Node가 없으면 `test.html`을 브라우저로 엽니다. 브라우저에서는 화면(편집 영역·쪽 나누기) 테스트까지 함께 돕니다.
- 수동 확인 목록은 [SPEC.md](SPEC.md)의 "수동 확인"에 있습니다.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html`, `styles.css` | 화면 |
| `app.js` | 메뉴·도구 모음·파일·미리보기·인쇄·임시 저장 동작 |
| `editor-dom.js` | 편집 화면 ↔ 문서 모델, 쪽 나누기 |
| `docmodel.js` | 문서 모델(문단 · 글자 조각)과 기본 모양 |
| `hwpx.js` | 문서 모델 ↔ HWPX |
| `zip.js`, `xml.js` | HWPX 안의 ZIP과 XML을 직접 읽고 쓰는 작은 도구 |
| `tests/` | 테스트 (`run-tests.js`는 node, `test.html`은 브라우저) |
